# PyUnicodeSymbol

一个使用 Python 和 PySide6 编写的本地查询和展示 Unicode 数学符号的 GUI 程序。

## 功能特性

- **海量符号库**：支持 1300+（实测 2000+）Unicode 数学符号。
- **专业分类**：覆盖逻辑/集合、范畴论、群论、拓扑、模型论、类型论（λ 演算）、上下标等多个专业领域。
- **异步加载**：采用多线程异步加载机制，切换分类及大批量显示时流畅不卡顿。
- **快速复用**：点击任意按钮即可自动复制符号到剪贴板。
- **全局搜索**：支持按名称（如 "lambda"）或十六进制代码（如 "2200"）实时搜索。
- **段落编号**：内置常用的带圈数字（①、② 等）段落编号分类。

## 运行环境

- Python 3.7+
- PySide6

## 如何使用

1. 安装依赖：
   ```bash
   pip install PySide6
   ```

2. 运行程序：
   ```bash
   python math_symbols_app.py
   ```

## 界面展示

程序界面包含左侧分类列表、顶部的搜索框以及中间的符号展示区。所有操作均采用异步模式，确保极速响应。
