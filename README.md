# PyUnicodeSymbol

一个使用 Python 和 PySide6 编写的本地查询和展示 Unicode 数学符号的 GUI 程序。

## 功能特性

- **全量区块支持**：通过解析本地 `Blocks.txt` 文件，支持 Unicode 标准中的所有 300+ 个区块（如：基础拉丁文、中日韩统一表意文字、表情符号等）。
- **专业数学分类**：保留并优化了精选的数学分类，方便快速查找。
- **模式切换**：左侧面板可快速在“精选数学”与“全量 Unicode”之间切换。
- **零网络访问**：完全基于本地 `Blocks.txt`，保护隐私且无外部依赖。

## 运行环境

- Python 3.7+
- PySide6

## 如何使用

1. 安装依赖：
   ```bash
   pip install PySide6
   ```

2. 运行程序：
   ```bash
   python math_symbols_app.py
   ```

## 界面展示

程序界面包含左侧分类列表、顶部的搜索框以及中间的符号展示区。所有操作均采用异步模式，确保极速响应。
